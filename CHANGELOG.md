# Changelog

Changes to AyuVahak releases are recorded here. Version numbers describe application releases; API versions and database migration versions are tracked separately.

## 0.1.0 — 2026-10-23

- First downloadable local reference distribution with an explicit Synthetic Demo or Empty first-run choice.
- Role-aware browser workspaces backed by server-authoritative grants and scopes.
- Optional, disabled-by-default, documentation-only Operator Support with a deterministic local acceptance provider and a paused external-provider configuration seam.
- Phase 13 production-hardening and Phase 14 productization acceptance are complete and frozen. See the release notes and acceptance records for evidence and limitations.
