# AyuVahak

AyuVahak is a care-coordination platform. This repository currently contains the Phase 1 engineering platform and no healthcare workflow implementation. The [architecture constitution](docs/architecture/constitution.md) defines the product and system boundaries.

New contributors should start with the [contributor guide](docs/development/contributor-guide.md). It covers the local Docker Compose environment, build and test commands, runtime configuration, migrations, architecture checks, observability, and troubleshooting.
