# AyuVahak

AyuVahak is a care-coordination platform. This repository implements the engineering platform and trust kernel, Care Service Directory, Capacity, Referral, deterministic advisory Matching/recommendations, and Transfer Coordination. The [architecture constitution](docs/architecture/constitution.md) defines the product and system boundaries.

New contributors should start with the [contributor guide](docs/development/contributor-guide.md). It covers the local Docker Compose environment, build and test commands, runtime configuration, migrations, architecture checks, observability, and troubleshooting.
