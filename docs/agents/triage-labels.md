# Triage labels

The local Markdown tracker uses the five default Matt Pocock triage roles:

| Role | Local status/label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the item |
| `needs-info` | `needs-info` | Waiting for reporter information |
| `ready-for-agent` | `ready-for-agent` | Fully specified for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

These labels do not authorize external actions. Phase 0 Wayfinder records use `Type:` and `Status:` metadata as described in `docs/agents/issue-tracker.md`.
