# Volume II Open Questions

**Review date:** 2026-10-08  
**Purpose:** Record only decisions not settled by the architecture/specification. Deployment configuration is not a global product architecture decision. Values must be explicit before the relevant safety-sensitive operation is enabled.

## Decision timing summary

- **MUST RESOLVE BEFORE VOLUME II IMPLEMENTATION: 0.** All context ownership, phase sequencing, application boundaries, state transitions, evidence semantics, security contracts, event use, retry behavior and acceptance gates are settled.
- **CAN RESOLVE DURING THE RELEVANT PHASE: 10.** These items are implementation-time or deployment-configuration inputs with a clear safe behavior when omitted; none permits an unsafe positive result.
- **DEFERRED TO LATER VOLUME / DEPLOYMENT GOVERNANCE: 5.** These require a selected jurisdiction, participating system, actual workload or later adapter/federation scope.
